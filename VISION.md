# Argus — The Immune System for AI Agents

> AI infrastructure can be perfectly healthy while AI behavior is catastrophically wrong.
>
> Argus detects behavioral failures that infrastructure monitoring cannot see
> and automatically recovers before users notice.
>
> Built on OpenTelemetry.
> Powered by SigNoz.

---

## The two superpowers (nothing else)

**PREVENT** — fast reflex · inline · milliseconds · in the gateway
> Agent produces a bad response → intercept → recover → user never notices.

**LEARN** — slow adaptation · windowed · seconds · through SigNoz
> Quality drifts over many requests while infra stays green → SigNoz detects the
> trend → Argus quarantines / reroutes the model.

Fast reflexes. Slow adaptation. An immune system.
